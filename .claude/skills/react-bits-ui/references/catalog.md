## Portfolio-fit shortlist (designer portfolio, premium & tasteful)
| Section | Best picks | Why |
|---|---|---|
| Hero headline | **SplitText** (effect `rise`, mask), **BlurText**, **RotatingText** (for role cycling), ShinyText (eyebrow) | Replaces typing effect with cinematic reveal |
| Hero background | **Aurora**, **Silk**, **Particles**, DarkVeil, Orb, Threads | Pick ONE; or use own R3F scene |
| Cursor | **TargetCursor** or subtle GlowCursor; ClickSpark for clicks | Fine-pointer only |
| About text | **ScrollReveal** (word-by-word scrub), ScrollFloat | Storytelling as you scroll |
| Profile photo | **ProfileCard** / **TiltedCard** | Holographic tilt card |
| Career timeline | **ScrollStack**, Stepper, AnimatedList | Stacked roles |
| Projects | **MagicBento**, **SpotlightCard**, ChromaGrid, CardSwap, PixelTransition (image→details) | Premium hover |
| Skills | **LogoLoop** (tool logos marquee), **ScrollVelocity**, GlassIcons | Replace CSS marquee |
| Stats | **CountUp** | |
| Travel gallery | **DomeGallery**, **CircularGallery**, Masonry, FlyingPosters, InfiniteMenu | 3D photo exploration |
| Memories | **Stack** (draggable photo stack), BounceCards, ImageTrail | |
| Hobbies | MagicBento (bento grid with spotlight + particles) | |
| Navigation | **PillNav**, **Dock**, GooeyNav, StaggeredMenu (mobile) | |
| Buttons/CTA | **Magnet**, StarBorder, SpecularButton | |
| Contact | ClickSpark on submit, SwipeToast for status, GlassSurface panel | |
| Section dividers | CurvedLoop, GradualBlur (edge fade), Noise overlay | |

Rule of taste: max **one "wow" effect per viewport**; everything else subtle. Heavy shader components (LiquidEther, SplashCursor, FluidGlass, Ballpit, Hyperspeed) are showpieces — use at most one, and never on mobile.
